# Face Recognition Attendance System

## 📌 Overview

The Face Recognition Attendance System is a computer vision project developed using Python and OpenCV to recognize registered faces and record attendance automatically.

The project captures face images, processes facial data, trains a recognition model, and identifies registered individuals during attendance sessions.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Detect faces using computer vision techniques.
- Collect and store face data for registered individuals.
- Train a face recognition model using collected face data.
- Recognize registered individuals from camera input.
- Record attendance automatically.
- Store attendance information in a CSV file.
